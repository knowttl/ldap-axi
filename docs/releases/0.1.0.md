# ldap-axi 0.1.0

The first ldap-axi release provides read-only access to Active Directory and generic LDAPv3 from an agent-facing CLI.
See [the README](../../README.md) for the Node requirement, npm package name, and common installation commands.

- Read entries, users, groups, and memberships with `entry search`, `entry show`, `user list`, `user show`, `user groups`, `group list`, `group show`, and `group members`.
- Inspect authentication selection and native-provider installation with `auth status`; `--offline` makes no directory connection.
- Use ambient GSSAPI/SSPI authentication, explicit simple authentication, or explicit anonymous access.
  Verified LDAPS and StartTLS use channel binding without a SASL security layer; plain LDAP uses mandatory GSSAPI confidentiality.
- Receive structured TOON output, bounded paged reads, decoded account attributes, and explicit incomplete-result diagnostics.
- Include fixes for LDAP result completeness, authentication diagnostics, generic LDAPv3 account state, and OpenLDAP Kerberos interoperability.
