# ldap-axi 0.1.1

This release prepares the npm package for compiler-free native-provider installation on both supported targets.
See the support matrix for the [npm bootstrap distinction](../support-matrix.md#installing-from-npm) and [release and provenance contract](../support-matrix.md#release-and-provenance).

Once published, follow [the README](../../README.md) for common installation commands.
See the [support matrix](../support-matrix.md#native-provider-installation-and-loading) for installation checks, platform requirements, and fallback behavior.

Directory access remains read-only.
See the support matrix for [verification evidence and remaining limits](../support-matrix.md#what-is-proved-and-what-is-not), including Windows SSPI behavior against a real domain.
