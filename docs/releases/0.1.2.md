# ldap-axi 0.1.2

This release prepares publication of `@knowttl/ldap-axi` from the fresh public [knowttl/ldap-axi repository](https://github.com/knowttl/ldap-axi).
The `v0.1.2` tag workflow builds and verifies Linux glibc x64 and Windows x64 native providers, stages the GitHub release, and publishes the tested npm archive through trusted publishing with provenance.
See the support matrix for the [release and provenance contract](../support-matrix.md#release-and-provenance).

The package bundles the Linux glibc x64 prebuild.
Windows x64 installation retrieves the matching release asset and verifies its SHA-256 digest against the package manifest.
See the [support matrix](../support-matrix.md#native-provider-installation-and-loading) for platform requirements and fallback behavior.

Directory access remains read-only, and CLI behavior is unchanged from 0.1.1.
Windows SSPI behavior against a real domain remains [unproved](../support-matrix.md#what-is-proved-and-what-is-not).
