# ldap-axi 0.1.5

The home view now shows one `npx skills add knowttl/ldap-axi --skill ldap-axi` line when the detected agent host lacks the skill.
Per-host folder checks look for the installed skill in the detected host's supported discovery roots.
Settings-listed and nested skill folders remain a documented limitation of these checks.
See the v1 design for [skill installation hints](../design/v1.md#141-the-home-view) and the support matrix for the [release and provenance contract](../support-matrix.md#release-and-provenance).
